# 语音视频感知（astrbot_plugin_av_sense）

> ## ⚠️ 装好之后怎么用
>
> 把下面这句话发给你的 AI（连同本文件和 `SETUP-FOR-AI.md`）：
>
> > 请帮我配置好 AstrBot 里的【语音视频感知】插件，并检测功能是否可用。
>
> AI 会检查 ffmpeg、语音识别、模型多模态能力，把插件配到「发语音能听懂、发视频能看懂」，
> 配完会告诉你哪些能力是通的。

## 它解决什么问题

QQ 里直接发的语音和视频，AstrBot 原本都当「一个文件名」丢掉：语音变成空消息（模型报错），
视频只留一句 `空消息、没找到链接（组件：Video）`。装了这个插件之后：

| 你发 | 她会怎样 |
| --- | --- |
| **语音** | 下载 → 转文字 → 按话回答你；听不清会直说「没听清，再说一遍」，不装懂 |
| **视频** | 只看**前 3 分钟**（长视频不卡）→ 抽帧当图片给模型看 + 音轨转文字 → 说出画面和内容 |

## 主要功能

1. **语音转文字**：优先用 AstrBot 自带的「语音转文字」provider；没配就退回本机 ASR 服务（可选）
2. **视频抽帧（混采）**
   - 基准帧：开头一帧 + **每 10 秒**一帧 + 最后一帧
   - 场景切换帧：画面真正换镜头时再补几帧（ffmpeg scene 检测）
   - 相似帧去重：和上一张几乎一样就丢掉
   - **至少 5 帧**：视频太短或画面不动，会自动压缩间隔/硬补到 5 帧
   - 上限 `max_frames`（默认 24），防止 3 分钟视频塞太多图
3. **只处理前 3 分钟**（`max_video_seconds`），音轨也只转前 3 分钟
4. **7 天自动清理**：插件存下来的图片/音频默认保留 7 天，然后后台自动删（可改）

## 前置

| 依赖 | 必需 | 说明 |
| --- | --- | --- |
| AstrBot ≥ 4.17（aiocqhttp） | ✅ | 协议端要能把语音/视频文件给出来 |
| `ffmpeg` / `ffprobe` | ✅ | 抽帧、抽音轨、转码。**装好并加进 PATH** |
| 一个能看图的模型 | ✅（视频需要） | 主模型必须支持图片输入，否则抽了帧也白搭 |
| 语音识别 | 视频音轨/语音需要 | 用 AstrBot 自带的「语音转文字」provider 就行；也可以指向本机 ASR |
| `meme_manager` 等 | ❌ | 不需要，本插件不调用别的插件 |

## 配置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable_voice` | true | 语音转文字 |
| `enable_video` | true | 视频抽帧 + 音轨 |
| `max_video_seconds` | 180 | 只处理前多少秒 |
| `frame_step_seconds` | 10 | 每多少秒一帧 |
| `min_frames` | 5 | 至少几帧（不够会压间隔） |
| `max_frames` | 24 | 最多几帧 |
| `frame_side` | 768 | 每帧最长边像素（越小越省 token） |
| `scene_detect` | true | 换镜头时补帧 |
| `scene_threshold` | 0.3 | 补帧敏感度 |
| `dedupe_diff` | 3.0 | 相似帧去重阈值 |
| `max_video_mb` | 200 | 下载大小上限 |
| `enable_asr` | true | 要不要转写声音 |
| `asr_url` | `http://127.0.0.1:9881/v1/audio/transcriptions` | 本机 ASR 兜底（可留空） |
| `retain_days` | 7 | 临时文件保留几天（0 = 不删） |
| `cleanup_interval_minutes` | 60 | 多久清理一次 |
| `timeout` | 120 | 单步超时（秒） |

## 常见问题

**Q：她回「没听清」？**
语音识别没配好，或者 ASR 服务没开。看日志有没有 `框架 STT 不可用` / `语音识别失败`。

**Q：视频只能说出画面、说不出内容？**
语音识别没通（视频音轨走同一套 STT）。要么配 AstrBot 的语音转文字，要么开本机 ASR。

**Q：视频很久才回？**
抽帧 + 转写要几秒；超过 3 分钟的部分不看。可以把 `frame_step_seconds` 调大、`max_frames` 调小。

**Q：磁盘会不会被塞满？**
默认 7 天自动清理（`retain_days`）。文件都在系统临时目录的 `av_sense/` 下。

**Q：需要装别的插件吗？**
不需要。语音识别要么用 AstrBot 自带的，要么自己起一个 ASR 服务（`SETUP-FOR-AI.md` 里有说明）。
