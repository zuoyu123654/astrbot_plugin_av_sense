# 语音视频感知（astrbot_plugin_av_sense）

她听得懂你发的语音、看得懂你发的视频。**本地识别，不花钱。**

## 需要的前置

| 依赖 | 必需 | 说明 |
| --- | --- | --- |
| AstrBot ≥ 4.17（aiocqhttp 协议端） | ✅ | — |
| `ffmpeg` **和** `ffprobe` | ✅ | 装好并加进 PATH（两个都要） |
| 语音识别 | 可选 | 默认走**本机**（faster-whisper / funasr，插件自动找、自动起）；本机没有就退到 AstrBot 自带的「语音转文字」；都没有也能用，只是听不见声音 |
| 能看图的模型 | 视频需要 | 抽出来的帧是当图片喂给模型的 |

不需要装别的插件。

## 功能

- **语音消息** → 转成文字再交给模型，她按你说的回答；听不清会直说「没听清」，不装懂
- **视频消息** → 只看**前 3 分钟**，抽关键帧当图片给她看，同时把里面的话转成文字
- 长视频不会卡（只看前 3 分钟）；画面几乎不变时会自动少抽几张
- 临时文件保留 **7 天**后自动删除（可改）
- 全程离线，不调用其它插件

## 怎么用

装好插件后，把这句话发给你的 AI：

> 请帮我配置好 AstrBot 里的【语音视频感知】插件，并验证是否可用。

AI 会照 `SETUP-FOR-AI.md` 检查 ffmpeg、语音识别、模型能不能看图，然后发一条语音和一条视频验证，
最后告诉你哪些能力通了。你自己想手动确认的话，看 `SETUP-FOR-AI.md` 第 5 节「验收」。

## 技术细节



1. **DeepSeek 的 `deepseek-chat` 能收图片。** 实测（2026-11-06）直接把一张图作为 `image_url` 发过去，
   它回了一段准确的画面描述（「Q版卡通风格的蓝发女仆…捧着拉花咖啡」）。所以「抽帧 → 当图片喂给它」
   这条路对 DeepSeek 是成立的，**不需要换模型**。
2. **语音识别默认用 faster-whisper**（本地、多语言、准）；实在不行退回 funasr（中文分词更细）。
2. **语音识别默认用 faster-whisper**（本地、多语言、准），不可用时退回 funasr（中文分词更细）。**`ffmpeg` 不做语音识别**，它只负责抽帧、抽音轨、转码、读时长。
   把声音变成文字必须有 ASR 模型（Whisper / funasr / 云端语音识别），ffmpeg 本身不会。
3. **语音和视频用的是同一套识别**：插件先试 AstrBot 自带的「语音转文字」provider，
   没有才退回本机 ASR 服务。所以只需配一次，视频里的话和你的语音都能转。

## 前置

| 依赖 | 必需 | 说明 |
| --- | --- | --- |
| AstrBot ≥ 4.17（aiocqhttp） | ✅ | 协议端要能把语音/视频文件给出来 |
| `ffmpeg` / `ffprobe` | ✅ | 抽帧、抽音轨、转码。**装好并加进 PATH** |
| 一个能看图的模型 | ✅（视频需要） | 主模型必须支持图片输入，否则抽了帧也白搭 |
| 语音识别 | 视频音轨/语音需要 | ① AstrBot 自带「语音转文字」provider（最省事）② 本机 **faster-whisper**（插件会自动找 python 并拉起服务，默认）③ funasr（中文） |
| `meme_manager` 等 | ❌ | 不需要，本插件不调用别的插件 |

## 配置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable_voice` | true | 语音转文字 |
| `enable_video` | true | 视频抽帧 + 音轨 |
| `max_video_seconds` | 180 | 只处理前多少秒 |
| `frame_step_seconds` | 10 | 每多少秒一帧 |
| `min_frames` | 5 | 至少几帧（不够会压间隔） |
| `max_frames` | 24 | 最多几帧 |
| `frame_side` | 768 | 每帧最长边像素（越小越省 token） |
| `scene_detect` | true | 换镜头时补帧 |
| `scene_threshold` | 0.3 | 补帧敏感度 |
| `dedupe_diff` | 3.0 | 相似帧去重阈值 |
| `max_video_mb` | 200 | 下载大小上限 |
| `enable_asr` | true | 要不要转写声音 |
| `asr_url` | `http://127.0.0.1:9881/v1/audio/transcriptions` | 本机 ASR 兜底（可留空） |
| `retain_days` | 7 | 临时文件保留几天（0 = 不删） |
| `cleanup_interval_minutes` | 60 | 多久清理一次 |
| `timeout` | 120 | 单步超时（秒） |

## 常见问题

**Q：她回「没听清」？**
语音识别没配好，或者 ASR 服务没开。看日志有没有 `框架 STT 不可用` / `语音识别失败`。

**Q：视频只能说出画面、说不出内容？**
语音识别没通（视频音轨走同一套 STT）。要么配 AstrBot 的语音转文字，要么开本机 ASR。

**Q：视频很久才回？**
抽帧 + 转写要几秒；超过 3 分钟的部分不看。可以把 `frame_step_seconds` 调大、`max_frames` 调小。

**Q：磁盘会不会被塞满？**
默认 7 天自动清理（`retain_days`）。文件都在系统临时目录的 `av_sense/` 下。

**Q：需要装别的插件吗？**
不需要。语音识别要么用 AstrBot 自带的，要么自己起一个 ASR 服务（`SETUP-FOR-AI.md` 里有说明）。
